# 剪辑放置与混音检查

## 时间线建议

以下是小屏/剧情/广告常见的起点，不是绝对数值。以接触帧、乐句和叙事信息为准。

| 动作 | 常见起点 | 目的 | 检查 |
| --- | --- | --- | --- |
| 接触声 | 与接触帧同步，或只提前极少量帧 | 可信、明确 | 不要因“更有力”而整体提前成假动作 |
| J-cut | 对白或提示声提前进入上一场 | 预期、空间切换 | 提前后上一场信息仍可读 |
| L-cut | 画面切换后保留 1 个自然尾音 | 连续、余韵 | 不拖住下一场节奏 |
| 转场 whoosh | 覆盖切换前后，峰值落在画面位移最大处 | 方向与速度 | 没有运动就不使用 |
| 冲击尾音 | 从接触帧自然衰减 | 重量与空间 | 下一句对白前先让出中频 |
| 静默 | 在高密度或重音后切入 | 对比、压迫 | 保留 room tone，避免数字静音感 |
| 音乐落点 | 卡在剪辑动作或产品卖点，而非机械整秒 | 节奏与记忆 | 不牺牲对白重音 |

## 混音工作顺序

1. **清理与同步**：对白去噪、去呼吸冲突、检查口型；环境声找无缝循环点；音效对齐接触帧。
2. **建立先导混音**：只听对白、环境声、关键 Foley。确保没有音乐也能理解场景。
3. **加入叙事重音**：放入不可缺的提示声、动作峰值、转场落点。
4. **加入音乐**：先确定音乐功能，再按对白和动态曲线做分段处理。
5. **加入设计层**：逐个确认新增声音的工作，删除重复层。
6. **空间与动态**：统一距离、混响、声像；处理掩蔽、低频堆积、尾音和段落呼吸。
7. **交付 QC**：按平台格式导出，检查响度、真峰值、单声道/手机播放和字幕时序。

## 平衡起点

- **对白是锚点。** 先让对白在完整混音中清楚，再让音效和音乐围绕它工作。
- 需要强调的短音效可以比对白峰值更高，但不能让持续音效长期压住对白中频。
- 音乐在密集对白下通常做宽而缓的分段 ducking；不要只靠单个压缩器自动抽吸。
- 中频掩蔽优先通过编曲、音色和段落让位解决，其次才是 EQ 大幅削减。
- 低频层不要全部落在同一频段；区分 sub、body 和低中频细节。
- 室内声、街道声、巨大空间的尾音要统一；同一个镜头不要混入互相排斥的空间感。
- 声像跟随可见/可信来源。手机、单声道或中央声道交付时，关键声效必须在折叠后仍存在。

平台响度以交付规范为准。没有给定规范时，把流媒体常用约 `-14 LUFS integrated`、真峰值不高于约 `-1 dBTP` 作为保守起点，再在目标平台复核；广播/影院/品牌规范可能不同，不应机械套用。

## 推荐轨道与总线

```
DIA_1      对白主轨
DIA_2      ADR / 补录
AMB_1      场景环境
AMB_2      远景/细节环境
FOLEY_1    人物动作
FOLEY_2    道具与材质
SFX_1      叙事设计音效
SFX_2      转场与强调
MUS_1      音乐主体
MUS_2      音乐铺底/尾音
PRINT      静场 room tone
```

可按项目调整，但保持“对白 / 环境 / Foley / SFX / 音乐 / 静场”的职责分离。命名加入场景、版本、状态或授权标记，例如：

`SC012_SFX_DOOR_metal_close_v03_processed`

## QC 清单

### 同步

- [ ] 接触声没有整体提前或滞后。
- [ ] 口型、脚步、道具和画面动作一致。
- [ ] 转场峰值落在真实动作或明确段落点。
- [ ] 长镜头没有循环接缝和音频漂移。

### 叙事

- [ ] 闭眼听也能听出地点、人物动作和主要情绪。
- [ ] 关键信息不是只靠一个容易漏听的弱音效。
- [ ] 悬念没有提前泄露答案。
- [ ] 静默前后有足够的声压和密度差。
- [ ] 结尾品牌/人物落点清楚。

### 混音

- [ ] 对白在手机扬声器、单声道和低音量下仍可懂。
- [ ] 低频没有掩蔽男声/女声基频，也没有持续浑浊。
- [ ] 重要瞬态不是只靠响度获得冲击。
- [ ] 重复素材已换变体或改变音高/时长/空间。
- [ ] 尾音没有被硬切，环境声切换没有明显断层。
- [ ] 没有削波；按目标平台检查 integrated loudness 和 true peak。
- [ ] 5.1/Atmos 项目检查 LFE 是否多余、环绕是否有可下混的关键信息。

### 交付

- [ ] 人声、音乐、音效、环境/静场可分别导出。
- [ ] 文件名含版本和日期，原始素材保留。
- [ ] 字幕/字卡不与关键声音事件冲突。
- [ ] 版权、授权和素材来源可追溯。
