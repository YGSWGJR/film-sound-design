## 场景决策表

| 画面类型 | 主锚点 | 辅助层 | 应避免 |
| --- | --- | --- | --- |
| 对话/剧情 | 对白与呼吸、衣料、手部接触 | 稳定室内外底噪、远处世界声 | 每个反应都加音乐重音；持续低频压住人声 |
| 悬疑/危险 | 听不见或看不清的来源声、距离变化 | 低频床、钟表/机械循环、极轻细节 | 一开始就放出完整怪物/威胁声；全程警报式噪音 |
| 动作 | 接触帧的起音与重量 | 材质细节、空气位移、空间尾音 | 同一 boom 重复；各层同时爆满；尾音全部截断 |
| 情绪转折 | 声音抽离、单一动机或一次材质细节 | 呼吸、环境余韵、音乐弱起 | 用大音效解释每一种情绪；情绪高点塞满声音 |
| 蒙太奇/预告 | 可数的节奏格与段落重音 | 变化密度、频率和空间，形成呼吸 | 把所有点都当成高潮；缺乏留白 |
| 场景/时间转场 | 共享的环境床、音乐动机或方向性声音 | J-cut、L-cut、声音桥 | 无运动也加 whoosh；环境声硬切跳变 |
| 科技/UI | 点击、确认、失败、进度、轻微电子脉冲 | 屏幕空间感、设备本体的细微声 | 所有交互同一种“未来感”提示音 |
| 汽车 | 真实动力/电机、轮胎与路面、空气与座舱 | 灯光、门、按键、材料接触、电子节奏 | 新能源车机械假引擎；低频压过产品细节 |
| 奢侈品/香氛 | 真实材质、克制的呼吸和空间 | 低频柔垫、留白、单一品牌动机 | 过度史诗音乐；廉价 whoosh 堆叠 |
| 食品/自然 | 液体、咬合、油脂、叶面、风、雨 | 近场材质与远景环境形成尺度 | 只有宏大环境，没有近场触感 |

## 声音语义速查

| 声音 | 常表达的语义 | 使用条件 |
| --- | --- | --- |
| 低频持续音/隆隆声 | 不安、规模、压迫、时间焦虑 | 有持续心理压力或巨大空间；要给中频留口 |
| 心跳/呼吸 | 主观身体感、恐惧、 exertion | 贴近角色视角；不要与对白争中频 |
| 钟表/机械循环 | 倒计时、秩序、失控前的控制 | 可逐渐加速、错拍或抽离 |
| 低频冲击/boom | 重量、突然性、段落落点 | 有对应重量或叙事落点；轮换音色和尾音 |
| riser/上升声 | 预期、加速、即将发生 | 必须有目标点；避免每 10 秒重复 |
| whoosh/空气位移 | 速度、方向、空间穿越 | 画面或空间确实移动；可分层做近远版本 |
| reverse/反向声 | 预感、回望、时间逆行 | 用于拉起注意力，结尾应落到明确事件 |
| 玻璃/金属/皮革摩擦 | 材质、厚度、价格感、触觉 | 与真实接触点对齐；近距离不要过湿 |
| 静电、脉冲、数字 glitch | 电子性、故障、信息流 | 需要克制并使用不同频段，避免统一“科技音” |
| 房间底噪/room tone | 真实空间、静默、连续感 | 每个场景建立稳定版本，避免循环接缝 |

声音语义不是固定词典。人物处境、镜头尺度和音乐语境会改变含义；先看叙事功能，再挑音色。

## 分层配方

### 冲击

1. **起音**：极短接触声或高频 snap，负责明确落点。
2. **主体**：中低频 thump/body，负责重量。
3. **尾音**：房间、街道或巨大空间的反射，负责尺度和余韵。
4. **细节**：碎片、尘土、金属振动或衣料位移，只在镜头需要时加入。

不要用同一个低频 boom 包办所有冲击。先判断是拳、车、门、玻璃、电子故障还是抽象情绪，再选择起音和尾音。

### Whoosh/空间穿越

- 前缘：空气位移或反向铺垫。
- 主体：带方向感的频段移动，而不是单一噪声。
- 到达：用接触声、短 hit 或环境切换确认落点。
- 立体声版本要考虑单声道折叠；重要信息不要只放在极端声像。

### UI/科技

- 点击：短、干净、有明确确认。
- 确认：一短一长的两层，避免每次三个音同时上升。
- 错误：音色变化大于单纯音量提高。
- 数据/信息流：脉冲、颗粒、低噪，密度按信息重要性变化。

### 汽车/新能源

- 基础动力：低频基音 + 负载变化 + 电流/电机高频。
- 路面：轮胎滚动、砂石、水、接缝分别处理。
- 车身：门、灯、按键、材质接触建立真实结构。
- 空气：风噪和穿过感随速度变化。
- 座舱：强调内外声压差，安静不是完全无声。

新能源广告可以不用传统引擎声，但不能没有动力叙事。用电机负载、电子脉冲、灯光反馈、车身共振和路面细节共同建立“速度、力量、精密”。

## 广告与产品片节奏

1. **前 3 秒只做一个主承诺。** 用最独特且有画面依据的声音建立钩子，不同时铺满音乐、旁白和三个音效。
2. **中段按卖点组织听觉格。** 每个功能点有独立动作—反馈—空间关系；长版本可重复节奏，短版本要删掉重复解释。
3. **品牌落点要能被记住。** 用一个稳定的品牌动机、材质声或品牌 sting，不要结尾突然换一套语言。
4. **高潮前先减。** 抽掉音乐、降低环境声或留一个单点，使最后的视觉/产品动作获得动态空间。
5. **CTA 用清晰而非最大声。** 人声、品牌音和最终画面必须同时可读。

可用一个简单密度曲线检查：`留白 → 建立 → 加速 → 短暂抽离 → 峰值 → 释放/品牌落点`。如果整条曲线一直很高，观众会把高潮当成噪声。

## 素材选择与真实性

优先顺序：

1. 与拍摄场景匹配的同期声和实录音效。
2. 可辨识材质、距离和空间一致的近场 Foley。
3. 经过音高、时长、滤波、混响等处理仍保持合理物理逻辑的设计音效。
4. 风格化 sound pack，只作为结构补充，不替代场景证据。

同一镜头需要多个版本时，先做**叙事版本**（信息最清楚）、再做**风格版本**（音乐性最强）、最后做**克制版本**（适合短视频小屏）。比较后选一个，不要把所有版本混在一起。
