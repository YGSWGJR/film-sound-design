# 学习片例

本技能的方法提炼自学以下公开视频教程。第三方视频内容归各自权利人所有。

| 视频 | 学到的核心点 |
| --- | --- |
| [诺兰玩了20年的听觉把戏](https://www.bilibili.com/video/BV1vHgu6LEPZ/) | 低频、节奏音和声音蒙太奇服务于时间结构 |
| [用耳朵看电影：斯皮尔伯格与音效设计](https://www.bilibili.com/video/BV19W411e7P2/) | 声音改变观众对画面的理解；画面外声音与预叙；混响与空间是意义的一部分 |
| [没有音乐怎么剪辑：用音效做节奏](https://www.bilibili.com/video/BV1BR4y1A71M/) | 节奏来自重音、留白与频率变化 |
| [用音效提升剪辑质感](https://www.bilibili.com/video/BV1Qr4y1S7r1/) | hit 用于重要节点；whoosh 用于转场；高频细节与低频重量分开思考 |
| [从 0 开始给广告片做声音设计](https://www.bilibili.com/video/BV1sS4y1E78F/) | 时间线按层组织；少量关键音效即可建立结构 |
| [Cyclist 音效设计全过程](https://www.bilibili.com/video/BV1Uu4y1o7jS/) | 音乐、氛围、关键声、高潮、夸张、动作的分层组织 |
| [VIVO X FOLD＋声音设计](https://www.bilibili.com/video/BV138411Z7NU/) | 按镜头拆解声音；高潮前压短、高潮释放 |
| [新能源汽车广告节奏声设计](https://www.bilibili.com/video/BV17HTw6HEwR/) | 不用声浪建立动力：电机负载、电子脉冲、路面与空气分工 |
| [影视混音基础概念和流程](https://www.bilibili.com/video/BV1SE411B7nK/) | 层级、空间、动态和交付检查框架 |
